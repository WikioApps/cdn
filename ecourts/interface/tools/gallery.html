The app is native Android. SVG animation is a browser capability; use the matching Android resources for Compose and Views.

This is an asset library. Neither eCourts branch was edited. The existing app icon and logo are preserved.

Light and dark assets have transparent backgrounds. Mono inherits currentColor when inline. For an external mono file, use it as a CSS mask and set the element’s background colour; an <img> cannot inherit its parent’s colour.

Android

Copy android/res/ into the future app’s resources. Static resources are named ecui_courthouse; motion resources are ecui_courthouse_animated. Matching day/night colours are included. Use the mono resources when the app supplies a tint.

Motion and accessibility

Most motions run once for 800 ms. Only loading and progress loop, and only while work is active. SVGs respect prefers-reduced-motion. Android callers must select the static resource when the app or system disables animation. Keep the original accessible name, selected state and touch target.

CDN availability

The relative paths above are built files. Public CDN paths require publication and verification; see the URL status file for the latest checks.
